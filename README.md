# ESP32 Voltage Oscilloscope

A real-time voltage visualization project using ESP32, a potentiometer, and a mobile application built with MIT App Inventor. This system works like a basic oscilloscope by displaying live voltage variations as a continuous graph on a smartphone.

---

## 📌 Project Overview

This project demonstrates how analog voltage data from a potentiometer can be:
- Read using an ESP32 microcontroller
- Transmitted wirelessly
- Displayed as a real-time graphical waveform in a mobile application

It is designed for educational purposes, IoT learning, and basic signal visualization.

## 🔌 Working Principle

1. The potentiometer produces an analog voltage.
2. The ESP32 reads this voltage through its ADC pin.
3. The voltage value is converted into digital data.
4. This data is sent wirelessly to the mobile application.
5. The app plots the voltage in real-time as a scrolling graph similar to an oscilloscope.

## 🚀 How to Run the Project

1. Upload the ESP32 code using Arduino IDE.
2. Connect the potentiometer to the ESP32 ADC pin.
3. Power the ESP32 using USB.
4. Install the mobile app on your Android device.
5. Connect the app with ESP32 using WiFi/Bluetooth.
6. Rotate the potentiometer and observe the live graph.
